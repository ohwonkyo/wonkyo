# wonkyo

This is a simple Express.js application that demonstrates the key pages for a survey platform.

## Key Pages
- **Dashboard**: Overview of surveys and responses
- **Survey Builder**: Create and edit surveys with various question types
- **Survey Link**: Mobile and desktop-friendly survey response page
- **Results/Statistics**: Charts and individual responses
- **Authentication**: Login and registration
- **Admin Page**: Manage users and survey permissions
- **Data Export**: Download data as CSV/Excel or send to external APIs

## Running
Install dependencies and start the server:

```bash
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000).
